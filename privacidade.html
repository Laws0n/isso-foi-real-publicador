Política de Privacidade — Publicador Isso Foi Real

Última atualização: 15 de novembro de 2026.

O Publicador Isso Foi Real é uma ferramenta de uso interno dos canais ISSO FOI REAL, THIS WAS REAL e ESTO FUE REAL. Ela serve apenas para enviar vídeos, capas e legendas produzidos pelo próprio projeto às contas do próprio projeto no YouTube.

Dados acessados

Com a autorização do titular da conta, a ferramenta usa a API do YouTube para enviar vídeos, definir capas e legendas e consultar o nome do canal autorizado. Ela não lê, coleta nem armazena dados de espectadores ou de terceiros.

Armazenamento e compartilhamento

Os tokens de acesso ficam apenas no computador do projeto e não são compartilhados, vendidos nem transferidos. O uso dos dados obtidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
